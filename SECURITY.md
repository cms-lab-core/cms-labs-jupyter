# Безопасность

Не публикуйте секреты, токены, kubeconfig, приватные ключи или данные пользователей в issues и pull requests.

Уязвимость следует сообщать сопровождающему приватно через GitHub Security Advisories репозитория. Если advisories недоступны, свяжитесь с владельцем @cms-lab-core напрямую через GitHub.

Пожалуйста, укажите затронутый commit, способ воспроизведения и оценку влияния.
